# Changelog

## 0.2.0

- Fixed signed numeric decoding and negative coordinates.
- Fixed FILE, MEMORY, and BATCH mode handling.
- Added strict IPv4 validation and optimized numeric index searches.
- Added UTF-8, Latin-1, and CP1251 decoding.
- Added batch lookup helpers, bounded caches, `clearCache()`, and `openShared()`.
- Added `close()` and explicit resource management support.
- Added stronger database header and size validation.
- Added CommonJS/ESM interoperability and improved TypeScript declarations.
- Added BSD-3-Clause licensing and upstream attribution.

## 0.1.0

- Fixed CommonJS and native ESM consumption.
- Corrected file-mode access and database decoding issues.
